# 1.7.0：排版库、封面与外观

## 排版库与封面

首页“排版库”展示默认封面、内置内页和自定义排版，每张卡片标注“封面”或“内页”。所有排版均可编辑、删除。删除内置项会在本机隐藏该项，删除自定义项会移出库；两者都不会修改已有纪念册。为保证随机生成可用，至少保留一个内页排版。

“恢复默认排版”会恢复内置排版和两个默认封面，重置对内置项的修改，保留自建排版；操作前明确确认。默认封面可直接编辑并保存，不必复制到新排版。自建排版可勾选“用作封面”，封面不会混入内页随机轮用。

新建窗口的“封面排版”可选择默认封面、自建封面，或任何可用内页排版。也可以选空白封面。编辑已有纪念册时，封面页的“封面排版”快捷入口可预览替换结果，确认后整次应用，并可撤销。

完整图片封面新增顶部居中文字框，框的 y 坐标为 0，文字内容自动填入纪念册标题，仍可自由移动和修改。两个默认封面均保留独立的城市角标。编辑模板时，“文字用途”可设固定文字、短语、纪念册标题或城市角标，每种标题/角标角色各最多一个；内页排版直接用作封面且没有指定标题角色时，以最大的文字框填入标题。

封面实际使用几张照片，就从后续内页分配中扣除几张；空白或纯文字封面不扣照片。页数预估、本地自动排版及 Codex 协议均采用同一分配规则，避免遗漏或重复照片。新建时默认选中全部贴纸，并提供“全选贴纸”“清空选择”。

## 界面与外观

“设置 → 外观”支持：

- 首页名称：1–24 个字符，默认“拾页”。
- 主题色：预设颜色或自选颜色；按钮、选择状态、焦点及画布选择框同步更新。主按钮按颜色亮度选择黑/白文字。
- 首页背景：导入本地 JPEG/PNG/WebP，调整浓度或移除。仅首页显示，编辑器与弹窗使用工作背景。
- 恢复默认外观：保留工程、素材和其他设置。

外观修改自动保存到本机。背景通过现有素材仓库导入、按摘要去重，使用压缩预览显示；设置只记录素材摘要，不保存任意 CSS、网络地址或外部文件路径。背景纳入原图回收保护，完整资料备份会携带该素材及设置。背景失效时首页仍可使用。

新建、设置与编辑器侧栏的折叠区统一为有浅底、边框的标题条，展开内容与标题间有分隔线；一级分区、二级折叠标题和字段说明分别使用不同字号、字重和中性色。主题色用于操作反馈，纪念册纸张与文字颜色保持为设计内容，不随软件主题改变。

## 编辑器操作

新增常用操作条：裁切取景、复制所选、上移/下移一层、锁定/解锁所选；封面页增加封面排版入口。无效操作禁用，锁定元素仍可通过快捷条解锁。单个元素可以在安全边距内左/中/右、上/中/下对齐，多选继续按选区对齐和分布。

新增 `Ctrl+]` 上移一层、`Ctrl+[` 下移一层。延续 Delete、方向键、Shift 加速、Ctrl+D、Ctrl+C/V、Ctrl+A、Ctrl+G / Ctrl+Shift+G、Ctrl+Z/Y 等快捷键；输入框获得焦点时不拦截文本编辑。

## 数据与兼容

- `LayoutTemplate.kind?: "cover"` 标记封面用途；模板页面仍为 content，实例化为封面时转为 cover，保持工程的首尾页约束。
- 默认封面稳定编号为 `builtin-cover-photo`、`builtin-cover-complete`。本机覆盖记录和隐藏列表保存于资源库设置，不依赖联网。
- `Settings` 增加可选 displayName、accentColor、homeBackground、homeBackgroundOpacity。旧设置无需重置；新字段缺省采用原外观。
- 已有工程与 PDF 不会因删排版、改模板或改软件外观而被自动改写。
- 延续固定目录覆盖打包：`out/delivery/` 与 `out/Memorybook-Windows-x64.zip`，不创建版本号文件夹。
- 覆盖交付目录保留用户已编辑的短语，分发 ZIP 独立使用默认短语；两份 SHA256.json 分别校验各自内容，避免个人短语被覆盖或误发。
