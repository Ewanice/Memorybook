# 1.5.0 版本说明

> 历史版本记录：自 1.5.1 起已移除卡密，当前启动、构建和发货方式见 [1.5.1 说明](15-v151-no-activation.md)。

本次在已有照片、贴纸、短语排版和 PDF 导出的基础上，补充异常资源处理、数据恢复与批量编辑。

## 资源与存储

- 损坏工程、贴纸、排版与字体分别隔离，健康资料继续可用；原始异常数据保留供恢复。
- 缺失图片以占位提示，可重新导入原文件修复；预览缓存失效时使用临时预览。
- 图片解码前检查尺寸；缓存继续使用压缩副本，PDF 使用原图。
- 工程备份使用流式压缩包与逐文件校验；素材缺失时仍可保留工程与其余健康资源。
- 新增“备份与恢复”设置：整库备份与合并导入、最近删除、恢复副本、异常记录与存储占用。
- 自动保存恢复副本和数据库副本；回收素材前检查工程、历史、删除记录及备份引用。

## 编辑与排版

- Shift 多选、框选、组合、对齐、分布，以及同册跨页复制粘贴。
- 双击照片直接裁切；属性输入提交时保存，避免一次拖动产生大量撤销记录。
- 套用排版前预览；照片超出排版容量时拆分到相邻新页，保留照片与文字贴纸。
- 自定义纸张尺寸、跨页预览、批量纸张与文字样式，以及排版草稿恢复。

## PDF 与 AI

- 导出前检查缺失资源、低分辨率、文字溢出与边界；可定位问题元素。
- 可选择页范围与出血，生成物理尺寸准确的 PDF，并可取消导出而不覆盖旧文件。
- AI 分组请求失败后，可复用本次已完成的有效分组；不自动重复付费请求。
- 支持逐条撤回 AI 修改；本地 Codex 自由生成时通过分组预览查看全部选中照片和贴纸。

## 验证与边界

2026-10-20 已通过类型检查、66 项自动测试、12 项桌面恢复与导出检查，以及 70 张照片与 8 张贴纸的 Codex 预览覆盖检查（含透明贴纸）。正式 Windows 包通过 ASAR 完整性、正式卡密、实际 EXE 启动，以及未指定开发数据目录时的完整文件夹存储验证。

PDF 为 RGB，不提供 CMYK / PDF-X 印前认证。AI 依赖用户所选服务的兼容接口、账号和额度；软件包未进行 Windows 发布者代码签名。当前版本并未经过另一台全新电脑与实体印刷验收。
