## 1. 设计主张：把回忆编成一本书

纪念册的视觉重点是照片和个人材料。票根、日期、城市与手写短句构成叙事线索；界面帮助整理和微调，不能抢走成品的注意力。

本方向借鉴本地 `canvas-design` 技能中 Analog Meditation 的照片主导与留白、Geometric Silence 的网格秩序，仅提取视觉原则用于产品规范。目前已据此实现桌面界面，实际效果以软件和运行验证截图为准。

页面通过大图、短句和小型凭证材料形成主次。每一页确定一个视觉中心，其他元素围绕它安排；相邻页用图片密度和空白变化形成翻阅节奏，不把所有页面都做成同一张海报。

纸面使用温暖的浅色，细纹理仅作为可关闭的背景素材。正文和说明保持清晰，装饰性字形留给短标题。栅格负责对齐，少量有意的偏移和旋转用于传达手账感。

精细程度体现在照片裁切、标题换行、页边距离和贴纸覆盖关系。模板应经过真实长标题、横竖照片和低清票根测试；不要依赖示例素材恰好合适才成立。

## 2. 编辑器布局

建议首版完整编辑最小视口 1280 × 800；窄窗口收起属性面板并提示更大窗口可获得完整体验。触屏精细编辑不作为首版验收范围。

```text
┌ 项目名 / 保存状态 ── 撤销 重做 ── 预览 ── 统一 AI 修改(5) ── 导出 PDF ┐
│ 页面 / 素材 / 模板 │                  工作区                   │ 属性 / 批注 │
│                   │                                           │             │
│ 封面              │             当前设计页                    │ 元素名称    │
│ 01 抵达           │                                           │ 位置 尺寸   │
│ 02 入场           │       选择框与批注标记仅在编辑时显示       │ 内容 样式   │
│ 03 舞台           │                                           │ 图层 / 锁定 │
│ + 添加页面        │                                           │ 添加批注    │
├───────────────────┴───────────────────────────────────────────┴─────────────┤
│ 第 4 / 18 页                适应页面 / 100%                辅助线与安全边距 │
└─────────────────────────────────────────────────────────────────────────────┘
```

左侧默认 220 px，右侧默认 300 px。画布外围使用中性灰，纸张使用真实页面背景色。视图缩放不改变实际尺寸；界面坐标在产品层展示 mm，字号展示 pt。

页面总览允许快速调整内页顺序。页面列表的“第几页”始终对应 PDF 物理页序；成品中可见的装饰页码是另一项设置，可选择封面不显示，不能用它替代真实页序。

## 3. 选择与编辑规则

| 操作 | 交互 |
| --- | --- |
| 单击元素 | 选中并展示对应属性 |
| 单击空白 | 取消选择，展示页面背景和模板信息 |
| 双击照片 | 进入裁切，出现“完成裁切”；Esc 退出并恢复进入前状态 |
| 双击文字 | 编辑内容；输入时快捷键作用于文字，不删除整层 |
| 拖动控制点 | 缩放外框；保持比例策略由元素类型决定 |
| 拖动旋转柄 | 旋转；提供角度输入与 0° 吸附 |
| 点击图层列表 | 选取被遮挡元素；锁定元素允许查看和添加批注 |
| Delete | 非文字输入状态下删除选中元素，可撤销 |
| Ctrl/Cmd + Z | 撤销；AI 运行时禁用 |
| 方向键 | 非文字输入状态微移元素；Shift 加速 |

首版以单元素精调为主，多选批量排版后置。照片、贴纸和文字均可自由移动；模板不永久限制位置。手动锁定需明确解锁后才能由 AI 改动，提交前列出锁定冲突。

## 4. 封面设计

### 4.1 三种组成方式

- 照片封面：用户上传背景照片，独立叠加标题、城市角标、可选日期。
- 完整封面：用户上传已经制作好的整张封面，以单张图片呈现；可再添加标题，但默认不叠加。
- 拼贴封面：用户选用照片框、票根、色块、文字组成的模板，各层独立可改。

上传图片中原有的文字属于图片像素，不能通过文本属性直接修改。只有新增的文字图层支持改字。

### 4.2 “明日世界 · 北京”建议版式

A5 竖版；舞台照片覆盖页面上部约 70%，底部留出纸色区域放标题与日期；城市角标放右上角。可选深色全幅照片版本，将标题置于有足够对比度的区域。

标题建议 28–36 pt，角标 9–12 pt，日期 8–10 pt。标题超过两行时提示用户缩小字号、调整框或缩短内容，不静默截断。遮罩、底色条作为独立形状层保留，可自行删除。

角标可以是城市、场次、日期或一句话；默认是普通可编辑文字，不限制字段只能填写城市。

## 5. 模板体系

模板按“风格套装 + 页面角色 + 素材容量”组织。每个槽位记录语义角色、边界、默认层级和样式。照片填充默认居中裁切，生成后提供裁切检查；首版不假设系统能识别人脸。

| 风格 | 色彩与排版 | 使用方式 |
| --- | --- | --- |
| 留白影集（默认） | 暖白、炭黑、灰绿色；大图与短文字 | 旅行、家庭、日常；模板最少依赖装饰素材 |
| 现场档案 | 深灰、米白、酸黄点缀；舞台大图、城市索引和票根 | 演唱会；每章有高对比度页面，避免整本暗底密集 |
| 手作拼贴 | 奶油色、砖红、少量蓝色；不规则叠放与纸边 | 用户素材多的手账场景；旋转保持克制，文字仍清晰 |

V1 先完成“留白影集”与“现场档案”两个套装，各套复用以下 8 种页面骨架；手作拼贴作为扩展套装。内置纹理和装饰必须有清楚来源与使用许可。

| 页面骨架 | 照片容量 | 文字与装饰 | 设计约束 |
| --- | --- | --- | --- |
| 封面 | 0–1 | 标题、角标、日期 | 标题与照片分别可编辑 |
| 章节扉页 | 0–1 | 章节标题、一句引言 | 留白至少约三分之一 |
| 单张主图 | 1 | 短说明、日期 | 视觉中心明确，避免自动裁掉关键区域 |
| 双图对照 | 2 | 一段说明 | 两图间距一致，可横竖混合 |
| 四格故事 | 4 | 页标题、简短图注 | 密度较高，减少贴纸 |
| 六图索引 | 6 | 标题或页码 | 用于记录连续瞬间，文字保持精简 |
| 票根与回忆 | 1–2 | 票根槽、一段文字、少量贴纸 | 票根默认完整显示而非裁切 |
| 尾页 | 0–1 | 结束语、日期 | 可作内页结尾；封底另由用户选择 |

默认 A5 页面建议外边距 10 mm、网格间距 4 mm、4 列栅格；正文建议 10–12 pt、图注 8–9 pt。实际样式要在打印尺寸下验证。贴纸可以跨过照片边框，但默认不得遮住标题和主要文字。

首次自动生成主要填充照片与用户明确输入的文字；未经提供的地点、人物名称、心情与事件不得自动编造。未上传票根时不强行生成票根页。

## 6. AI 批注界面

选中元素后，右侧“批注”页签提供多行输入框，提示语为“希望这个元素怎么改？例如：放大一点，保留人物头部”。未输入时仅为占位提示，不作为实际任务。

元素角落显示编号标记，画布标记不进入 PDF。列表用“第 3 页 · 照片 2”定位对象，保存稳定 ID，页码变化后标签随之更新。

批注支持以下可见状态：保存中、待提交、需复核、处理中、已应用、需处理。颜色之外同时展示文字与图标，避免单靠颜色辨别。

任务运行时画布保留可浏览状态，顶部显示持续状态条：“正在根据 5 条批注修改纪念册。完成前暂时不能编辑。”旁边保留“取消修改”。不要用完全遮挡画布且无法关闭的大弹窗。

完成结果面板列出每条批注的处理结果，例如“第 3 页 · 标题：字号 28 → 32 pt，颜色改为暖黄色”。点击定位对应页面并切换修改前/后。未处理的条目展示具体原因和再次编辑入口。

## 7. 关键状态文案

| 情境 | 推荐文案与操作 |
| --- | --- |
| 新项目无素材 | 上传你的照片，也可以先选模板，从空白页面开始 |
| 封面未上传 | 先用纯色封面，之后随时替换 |
| 图片分辨率较低 | 这张照片在当前大小下可能不够清晰。可缩小显示或换原图 |
| 保存失败 | 最新修改尚未保存，请重试。保留当前页面以免丢失 |
| 批注目标已改变 | 元素已修改，请检查这条批注是否仍然适用 |
| AI 无待处理批注 | 先选择一个元素，写下你希望它怎么改 |
| AI 正在取消 | 正在结束本次修改，即将恢复编辑（仅等待本地事务，不等待网络） |
| AI 已取消 | 本次修改已取消，原稿与批注已保留 |
| AI 系统失败 | 本次修改未应用，原稿未改变。可以重试 |
| 部分语义请求未执行 | 已完成 4 条，另有 1 条需要补充说明 |
| PDF 正在生成 | 正在导出版本 12，共 18 页。你可以继续编辑 |

## 8. 原型评审任务

用同一个 12 页演唱会样例完成：新建与上传、选择风格、封面输入、照片裁切、文字换行、票根添加、页面排序、跨三页添加批注、AI 取消、结果对比、PDF 检查。原型需要包含正常态、长标题、空素材、保存失败与 AI 运行态，不能只绘制一张静态理想界面。

## 9. 软件界面：美观、克制、服务操作

界面与纪念册模板分别设计：纪念册可以有拼贴、纹理和强烈色彩，编辑器保持中性、安静。统一字体层级、间距、控件高度、边框和圆角；主要操作使用一个强调色，状态色只表达状态。设计令牌集中管理，不在不同页面随意拼接样式。

不使用装饰性大面积渐变、玻璃效果、频繁弹窗、无意义动画或占据工作区的宣传卡片。动效只用于说明展开、定位和任务状态，并遵循系统减少动画偏好。常用按钮保留文字或明确提示，不要求新用户猜图标；键盘焦点可见，状态不只靠颜色表达。

默认保持画布最大可用面积，属性按选中对象展示，精确参数折叠到“更多”。界面缩放后不能遮住导出、取消、确认等关键操作；浅色纸张与深色照片均应能辨认边界，长中文标签和错误信息不被截断到无法理解。

设置使用一个窗口或页面，按“通用 / 文件与导出 / AI / 授权与关于”分组，不嵌套多层菜单。每项给简短标签、必要说明和明确当前值；修改自动保存，破坏性操作单独确认。完整设置及作用范围见 [产品需求第 9 节](01-产品需求文档.md#9-必要设置与默认行为)。

视觉验收覆盖空项目、真实满内容页面、长标题、保存失败、AI 运行和设置页；在 100%/125%/150% 界面缩放下检查清晰度、遮挡和操作可达性。不得以增加装饰数量作为“更美观”的验收依据。

## 1.1.0 排版与首页补充

四套构图采用固定照片、文字和贴纸分区，遵循统一比例网格、照片主导、字级有序与受控旋转；参考 [设计方向及预览](08-四套固定排版与素材库.md)。新建窗口直接展示四套缩略预览，可选单套或交替使用。首页在纪念册下方加入贴纸库/短语库切换，上传与重读不要求进入工程。


## 1.2.0 更新

当前生成不再单选模板：全部照片排版与自定义排版随机轮用。软件内可编辑短语库、新建和编辑排版，并设置页码开关及位置；本地 Codex 自动检测连接，可按固定排版或自由设计生成，提示词与 skill 在设置中配置。数据、交互及技术细节以 [1.2.0 说明](09-随机排版与本地Codex.md) 为准，取代此前单选/四套交替的描述。
