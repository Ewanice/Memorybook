# 离线使用与自动发货

自 1.5.1 起，软件不再提供卡密或激活功能。打开软件即可使用，不要求账号、设备绑定、公钥或授权服务器。此前的统一卡密方案已废止，具体变更见 [1.5.1 说明](15-v151-no-activation.md)。

## 获取和交付

GitHub 提供相同软件免费获取。平台可以提供完整软件包的便捷交付、图文教程和明确范围的技术服务；自愿赞助单独说明，不影响软件功能。

平台下单 → 自动发送云盘链接、提取码（如有）和使用说明 → 下载完整 ZIP → 解压到可写英文路径 → 打开 Memorybook.exe → 开始制作。

平台使用固定内容自动发货即可，无需维护卡密库存或绑定订单。补发返回相同的下载信息；更新后替换下载包与版本说明。

## 发货说明示例

> 下载 Windows x64 完整文件夹版，完整解压到可写的英文目录，例如 D:/Memorybook，再打开 Memorybook/Memorybook.exe。无需卡密、激活或登录。请保留同目录的 DLL、locales、resources、materials 与 phrases.txt。
>
> 普通排版、编辑与 PDF 导出可以离线完成。AI 为可选功能，使用你自己的 API Key 或本地 Codex 账户额度，软件不包含 AI 额度。
>
> 升级前关闭软件并做好备份，保留 data、materials/imported-fonts 和自行编辑的 phrases.txt。

## 发布检查

- 完整包与源码使用相同版本，提供逐文件校验与压缩包摘要。
- 不包含用户工程、API Key、个人素材库、测试数据或构建私密资料。
- 新目录首次启动直接显示首页，已有资料升级后正常读取。
- 保留第三方许可、使用说明与设置中的诊断功能。
- Windows 发布者代码签名仍为可选项；当前交付未签名完整包。
- 软件只在用户主动调用 AI 时请求对应服务，不联网激活，不自动上传工程或统计。
