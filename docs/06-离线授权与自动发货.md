# 离线授权与自动发货

> 1.3.0 更新（2026-10-15）：平台自动发货内容改为完整文件夹 ZIP、统一卡密与快速上手。买方必须完整解压，保留 DLL、locales、resources 和素材；默认资料保存在软件旁，升级保留数据、导入字体和短语库。 完整规则见 [软件目录存储与纸张字体](10-软件目录存储与纸张字体.md)。

版本：v0.5 ｜ 日期：2026-10-15

## 1. 已确定：所有用户使用同一个卡密

按最新要求，取消每人独立码、卡密库存、席位唯一性及订单绑定。所有买家收到相同的正式卡密，在软件首次运行时粘贴一次，以后在本机验证，不联网激活、不绑定机器、不要求登录。

统一卡密仍采用 Ed25519 签名许可证：载荷包含 productId、majorVersion、edition、keyId 和固定的发布批次 licenseId。软件仅包含公钥，私钥由卖方保存。签名覆盖载荷原始字节；客户端严格验证格式、签名、产品与支持的大版本。卡密内容不放入客户端作为字符串比较，也不在源代码内置一个通用绕过密码。

这可以拒绝伪造或篡改的卡密，但无法区分买家、追查具体泄漏者、限制使用台数，或阻止软件与真码一起转卖。已离线分发版本无法远程撤销，代码签名和完整性保护也不能保证不可破解。不实现无依据的本地“首次机器绑定”。

## 2. 发货流程

卖方生成一份正式签名卡密 → 将签名安装包上传云盘 → 在平台设置固定发货内容 → 买家支付后自动收到相同下载信息与卡密 → 安装并粘贴卡密 → 离线使用。

平台只需支持虚拟商品固定内容自动发货，不要求独立卡密库存或定制订单 API。重复通知和补发返回相同内容。安装包更新时核对卡密支持范围，保持当前大版本用户可用。

发货模板：

> 下载地址：正式云盘链接
>
> 提取码：如有则填写
>
> 软件卡密：统一正式卡密
>
> 下载 Windows 完整文件夹压缩包，完整解压后运行 Memorybook.exe，首次启动粘贴卡密即可。编辑和 PDF 导出可离线使用，AI 需要用户配置自己的 API，调用费用由该平台账户承担。
>
> 支持系统、版本说明、售后入口：正式发布时填写。

## 3. 签发与发布规则

- 签发工具与客户端分离；私钥不得进入仓库、安装包、工程备份或云盘。开发测试采用独立临时密钥，正式构建不接受测试密钥。
- 正式公钥在发布构建前配置；缺少公钥时构建失败，不自动生成或绕过。正式卡密由卖方在受控环境签发一次，发布给所有买家。
- 正常验签成功后保存卡密；新卡密错误不得覆盖原有效卡密。当前大版本永久离线使用，不依赖系统时间判断到期。
- 退款不能让单个买家手中的通用码失效；不可宣称具备单用户封禁、单机限制或泄漏追踪能力。
- 用户 API Key 与离线通用码分离，软件不分发模型密钥、不提供统一 AI 额度。
- 发布前准备第三方许可、安装说明，并验证一次真实下单到断网导出的完整流程。Windows 代码签名按当前选择为可选项；默认未签名包，发货说明应说明可能出现未知发布者提示。

该授权调整不改变正式架构、必要设置、离线边界和简洁界面要求。
