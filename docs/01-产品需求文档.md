## 1. 产品定义

让没有专业排版经验的用户，也能把照片、贴纸、票根和文字整理成一本有叙事、有设计感、可导出保存的纪念册。

核心体验：上传素材 → 选择风格与模板 → 生成整本初稿 → 自由微调或添加 AI 批注 → 一次应用 AI 修改 → 检查并导出逐页 PDF。

“明日世界 · 北京”演唱会纪念册是首个样例场景；同一套能力应适用于旅行、毕业、恋爱、家庭与个人年度回顾。正式产品名称待定，文档统一称“纪念册设计器”。

### 1.1 用户与任务

| 用户 | 希望完成的任务 | 当前阻力 | 产品应提供的帮助 |
| --- | --- | --- | --- |
| 演唱会观众 | 把舞台照片、合照、票根做成纪念册 | 素材多、缺少设计思路 | 有主题的模板、批量导入、照片顺序可控 |
| 旅行记录者 | 按行程组织多页回忆 | 页数一多，风格容易混乱 | 页面管理、成套模板、统一文字样式 |
| 手账与拼贴爱好者 | 自由摆放自己收集的元素 | 固定模板限制创作 | 模板生成后全部可编辑，自带透明贴纸 |
| 不熟悉设计工具的用户 | 描述哪里不满意，让 AI 帮忙改 | 不知道应调整哪些参数 | 点选元素写批注，跨页统一处理 |

### 1.2 成功的具体表现

- 用户不需要 AI，也能完成一本纪念册并导出。
- 用户生成初稿后，不需要重新制作就能替换照片、改变裁切、移动贴纸、修改标题。
- 用户可以对多页的不同元素写批注，统一执行后知道每条批注是否被落实。
- PDF 的第 N 页就是编辑器中的第 N 个设计页；封面、封底计入页面序列。
- 项目保留可编辑结构，而不是只保存页面截图。

## 2. 正式交付范围与实现顺序

按已确定的完整商业产品进行架构设计和编码，不以 MVP、演示版或临时实现作为交付目标。下表 V1/V1.1 仅表示基础模块与 AI 模块的实现顺序，不代表先售卖一个功能缩水的版本；正式交付应包含两阶段约定能力、必要设置和统一授权。明确列入“后续”及“非目标”的能力不因这一要求自动纳入范围。

首版采用 Windows 离线桌面编辑器，使用 Electron 封装本地界面；面向鼠标和键盘操作。移动端精细编辑、多人协作和商业印刷流程后置。默认三步生成：选照片、选风格、生成；尺寸、密度和精确属性收进高级选项。

| 能力 | V1 基础版 | V1.1 AI 批注版 | 后续 |
| --- | --- | --- | --- |
| 素材上传、模板生成、多页编辑、项目恢复 | 完整交付 | 延续 | 更丰富素材管理 |
| 封面图片、独立标题和角标 | 完整交付 | AI 可修改独立元素 | 更多创意封面 |
| 单元素移动、缩放、旋转、文字样式 | 完整交付 | AI 使用相同操作模型 | 路径文字、复杂矢量 |
| 逐页 PDF 导出 | 完整交付 | 延续 | 专业出血、色彩管理、印厂对接 |
| 跨页元素批注 | 数据协议在 V1 定义 | 完整界面与批量执行 | 页级、全书级独立批注 |
| AI 改文案、改布局、改样式 | 保留结构与操作接口 | 完整交付 | 图片生成、抠图、内容修复 |
| 登录、云同步 | 无账号登录、无云同步；离线授权 | 用户自带 API Key 直接调用平台 | 跨设备通过工程包迁移 |

分阶段用于技术验证和验收，不允许以“以后重构”为理由省略正式数据模型、事务、权限边界、版本迁移和故障处理。完整目标包含 V1.1；未接入 AI 时，不展示会模拟成功的“AI 修改”入口，未完成正式范围不得标记为可售卖成品。

## 3. 产品信息架构

- 我的纪念册：新建、打开、重命名、复制、删除、最近编辑时间、封面缩略图。
- 新建向导：主题与尺寸、素材导入、模板风格、照片顺序、生成预览。
- 编辑器：页面导航、素材库、画布、元素属性、批注列表、预览与导出。
- 导出结果：检查结果、文件生成进度、下载与重试。
- 设置：通用、文件与导出、AI、关于；全局偏好与当前纪念册内容分开。

项目删除需确认；明确删除的是项目，不能连带删除其他项目引用的共用素材。

## 4. 主流程

### 4.1 创建与生成初稿

1. 输入项目名称，可选填写主题标题“明日世界”、城市角标“北京”、日期。
2. 选择尺寸：默认 A5 竖版 148 × 210 mm；另提供 210 × 210 mm 方形。一本书所有页面尺寸一致，V1 创建后不直接切换尺寸。
3. 上传照片和装饰素材；用户可将同一素材标记为照片、贴纸、票根等用途。
4. 选择成套风格和照片密度：舒展（每页 1–2 张）、标准（2–4 张）、丰富（4–6 张）。模板槽位为准，密度影响模板选择，不将所有页硬性塞满。
5. 排序素材，默认上传顺序；可手动拖动排序。按拍摄时间排序仅在元数据可用时提供，缺失时间的素材集中放在末尾并提示。
6. 指定封面素材，允许跳过并使用纯色封面；用户也可上传一张已经设计好的完整封面。
7. 根据素材数量与模板容量计算建议页数，展示“封面 + 内页 + 可选封底”的准确数量；生成前可调整排序、删选照片和密度。
8. 生成可编辑初稿。首版使用模板规则，不依赖 AI。照片默认不重复填充；素材不足时选更少槽位的模板，不能悄悄复制照片或填入虚构回忆。

空项目也可进入编辑器，默认封面和一张空白内页。空槽位不会直接出现在成品中，导出前必须处理。

### 4.2 自由编辑

用户选择元素后，可拖动位置、缩放、旋转、调整层级、复制、删除和锁定。照片框大小与照片裁切是两个操作：拖动外框改变占位，双击进入裁切模式调整框内画面。

文字可编辑内容、字体、字号、颜色、粗细、对齐、行距和字间距。缩放文字框只改变排版区域和换行，不自动改变字号；字号通过属性面板调整。照片与贴纸默认保持宽高比；照片框可改比例，图片本身不得被拉伸。

每一次连续拖动或输入合并为一个撤销步骤；支持撤销和重做。用户锁定元素后不能误拖，仍可选中查看属性和批注。

### 4.3 AI 批注与统一修改

1. 选中元素，点击“添加批注”。输入如“这张照片放大一些，保留人物头部”“标题改成暖黄色”。
2. 输入停止 500 ms 后自动保存，失焦立即保存；显示保存中、已保存或保存失败。无需手动点击保存。
3. 可以跨页继续写。批注面板按页分组，显示目标缩略图、元素名称、内容和状态。点击条目定位元素。
4. 点击“统一 AI 修改（N 条）”。先完成保存，校验批注目标和项目版本；有失败或冲突时不能启动。
5. 创建全书一致版本的任务。运行期间整本书只读，禁止移动、文字修改、素材替换、页面增删排序、批注变更、撤销与重做。允许浏览页面、缩放视图、查看批注和取消任务；暂不允许导出，避免用户误以为导出了 AI 完成后的版本。
6. AI 生成结构化修改方案，系统验证后一次性应用。完成后解除锁定，显示“已修改 X 项、需处理 Y 项”，提供修改前后查看和“撤销本次 AI 修改”。
7. 未能执行的批注保留内容与原因，可编辑后重新提交。成功批注标记已应用，默认不重复提交。

同一元素首版保留一条活动批注，用户可在一条中描述多项修改；再次输入是更新原批注。多条相互冲突的要求需要用户消解，系统不能默默猜测。

AI 的作用范围由批注明确控制。默认只修改批注元素；如果用户写“与旁边文字拉开距离”，可读取页面上下文，但未经授权不移动旁边文字。若必须改其他元素才能完成，则返回需补充说明。整本统一风格调整在首版可通过多个元素批注完成，独立全书指令后置。

### 4.4 取消、失败与恢复

- 取消由本机主进程原子接受，立即使任务结果失效并解除编辑锁；中止对应的 API 请求，但不等待网络确认。晚到的结果不能覆盖项目。
- 断网仍可本地取消；AI 平台只返回建议，不具备本地工程写入权。实际已发生的 AI 费用按用户所选平台规则结算。
- 已完成提交的任务不能再取消，提示“修改已完成，可撤销本次修改”。
- 模型超时、响应无效、素材不可访问或结构验证失败：整批不应用，恢复原稿，批注保留。
- 对于明确不支持或含义不清的批注，可将该条标记需处理，其余有效项统一提交；结果面板必须列出未执行项。系统错误导致的半套方案不得伪装为部分成功。
- 仅界面重载时向本机主进程恢复任务状态；应用进程重启后中断任务失效，保留原稿与批注并解锁，不自动重新发送或重复扣费。本地协调器负责超时处理。
- 整批撤销作为一个历史步骤。若后续又有人工修改，须先按顺序撤销这些修改，不能直接覆盖当前版本。

## 5. 功能要求

| 编号 | 功能 | 规则与验收要点 |
| --- | --- | --- |
| F01 | 素材导入 | V1 支持 JPEG、PNG、WebP；透明 PNG/WebP 保留透明通道。文件失败逐项提示，成功项继续保留；SVG、PDF、HEIC 先明确提示需转换，不假装支持 |
| F02 | 素材管理 | 查看原图、重命名、筛选、查看引用次数；已被使用的素材不能直接删掉文件，必须先替换或移除引用 |
| F03 | 模板排版 | 定义照片、贴纸、文字槽位和默认样式；实例化后变成独立元素；再次套版需预览并确认，保留撤销能力 |
| F04 | 封面 | 图片、标题、角标为独立图层；用户可自由改内容、颜色、位置和大小；完整封面图片模式默认隐藏额外标题与角标，避免重复叠字 |
| F05 | 页面管理 | 新增空白页或模板页、复制、删除、拖动排序；封面固定首位，可选封底固定末位；删除页提示其元素与活动批注将一起移除，支持撤销 |
| F06 | 元素编辑 | 数值位置、尺寸与角度；边界和中心吸附；层级列表；锁定、隐藏；照片替换保留框、重置裁切并提供预览 |
| F07 | 文本编辑 | 支持中文、多行、字体与颜色；溢出提示；字体缺失时不能静默换字；V1 使用受支持字体集，不开放任意字体文件上传 |
| F08 | 历史与保存 | 编辑自动保存，显示状态；离开前处理未完成保存；保存失败保留当前编辑并可重试；历史采用命令与快照，不以截图替代源文档 |
| F09 | 批注 | 自动保存、元素定位、跨页分组、待处理数量；删除元素使其批注失效；替换图片或修改目标后显示需复核，不自动套用旧指令 |
| F10 | AI 批量修改 | 版本快照、全书只读、取消、超时、原子提交、结果摘要与整批撤销；模型只能提出受限操作 |
| F11 | 预览 | 单页翻阅与页面总览；不显示选择框、批注标记、裁切操作层、安全线 |
| F12 | PDF | 按页面序列逐页导出，保留物理尺寸、文字与图片裁切；封面占第一页；不拼跨页，不制作印刷拼版 |
| F13 | 必要设置 | 本地持久化偏好；支持界面缩放、辅助线与吸附默认值、新项目默认尺寸、导出目录与质量、缓存管理、AI 开关、授权与版本查看；具体规则见第 9 节 |
| F14 | 无激活使用与商业交付 | 软件打开即可使用；平台固定内容自动发送完整包与教程，可提供技术服务与自愿赞助 |

### 5.1 PDF 的具体定义

输出文件名默认为“项目名_日期.pdf”。一张设计画布对应 PDF 的一页，页面顺序与编辑器一致，不自动补空白页或凑偶数。

提供“分享”和“高清”两个预设：分享倾向较小文件，高清以图片有效分辨率 300 DPI 为目标。用户原图像素不足时显示提示，不声称提升预设会补充细节。V1 为 RGB 数字分享与常规打印用途，不承诺印厂级交付。

导出前检查：素材失效、空照片槽、文字溢出、字体不可用、低分辨率、越界元素。素材缺失、空照片槽和字体无法正确渲染阻止导出；低分辨率、文字溢出和越界允许用户查看并确认继续。越界内容按页边缘裁切。

导出固定已保存版本，生成过程中允许继续编辑，但界面注明“正在导出版本 N”；新修改不进入本次文件。导出与 AI 任务互斥：导出期间不可启动 AI，AI 期间不可发起导出。失败可以重试，不能把不完整 PDF 当成完成结果。

## 6. 数据保存与素材隐私

项目内容、素材引用、模板版本、页面和元素 ID、批注与修改历史均需要持久化。离开、刷新与重新打开不得丢失已确认保存的内容。

确定采用 SQLite 与本地素材目录持久化，并提供可恢复工程包。不把浏览器短期缓存当成可靠项目备份，不依赖云存储或登录。软件安装、授权验证、编辑与导出均可离线完成。

AI 接入时清楚说明哪些页面图片、文字和批注将发送给模型。默认按任务最小范围提供数据，移除照片定位等无关元数据；原图与访问令牌不写入调试日志。用户素材是私有项目资产，不自动进入公共素材库。

## 7. 非功能目标与产品指标

以下是待基准验证的设计目标：一本 100 页、每页 30 个可见元素、全书 500 个素材引用；单文件上传上限暂定 25 MB。遇到限制应在生成前说明，不能完成一半才丢数据。

性能目标：约定测试设备和网络后，常见拖动保持流畅（目标 45 FPS 以上），普通编辑在 2 秒内反馈保存状态；100 页高清导出允许后台执行并持续展示真实阶段。AI 展示提交、分析、校验、应用等阶段，不伪造精确百分比。

产品验证指标：首次 PDF 导出完成率、从导入到初稿时间、模板生成后人工调整量、AI 批注落实率、AI 整批撤销率、项目恢复成功率、导出失败率。首轮测试先获取基线，不预设缺乏依据的商业增长目标。

## 8. 非目标

V1 不包含多人实时协作、素材商城、在线印刷下单、社交发布、图像内容生成、复杂矢量绘制、自动人物识别或照片人脸分析。AI 图片处理可以后接独立能力，不与排版修改混在首轮范围中。

## 9. 必要设置与默认行为

设置入口固定放在主界面菜单中，编辑器内也可到达。提供合理默认值，用户不进入设置也能完成制作。

| 分组 | 设置项 | 默认与规则 |
| --- | --- | --- |
| 通用 | 界面缩放 | 默认 100%，提供 100%/125%/150%；只影响软件界面，不影响设计尺寸和 PDF；小窗口配合面板折叠 |
| 通用 | 对齐辅助线、自动吸附默认值 | 默认开启；当前编辑视图可临时切换，不改变页面元素 |
| 文件与导出 | 新项目默认尺寸 | A5 竖版，可选方形；只作用于之后新建项目，不重排当前册 |
| 文件与导出 | 默认 PDF 质量、导出目录 | 默认高清；首次导出选择目录，之后记住；每次导出仍可覆盖选择 |
| 文件与导出 | 打开项目数据目录、清理预览缓存 | 显示缓存占用；清理需确认，只删可重建缓存，绝不删除原图、工程、历史或授权 |
| AI | 允许使用 AI | 默认关闭，首次主动使用时说明上传范围并由用户开启；开启不产生后台调用 |
| AI | 用户自带 API 配置 | 地址、模型、协议、加密 Key、可选图片预览与严格输出；支持真实连接测试和移除 Key；费用与余额由用户平台管理，不影响离线授权 |
| 关于 | 版本、第三方许可声明 | 均可离线查看；无需激活；无自动检查更新 |

设置修改自动保存，成功后才显示已生效；失败保留原值并提示重试。目录无权限或失效时让用户重新选择，不静默改存其他地方。无效的新授权不覆盖当前合法授权。

AI 正在运行时关闭 AI，先说明会取消当前任务；确认后执行本地取消并关闭网络能力，用户取消确认则保持原状态。重置默认设置若会关闭运行中的 AI，也遵循同样规则。

自动保存属于可靠性保障，不提供关闭选项。工程备份/导入、当前册尺寸和具体元素属性放在相应工作流程中，不把所有操作塞进设置。首版不提供无需求支撑的主题编辑器、模型参数面板和任意服务地址输入。
