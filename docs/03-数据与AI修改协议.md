## 1. 文档结构

| 对象 | 实际字段 | 约束 |
| --- | --- | --- |
| Album | schemaVersion、id、revision、name、updatedAt、size、theme、pages、assets、annotations | schemaVersion 为 1；revision 用于并发校验；size 为整本统一的 width/height |
| Page | id、role、background、elements | role 为 cover/content/backCover；封面第一、封底最后 |
| 元素公共字段 | id、type、name、frame、rotation、opacity、locked、visible | frame 包含 x/y/width/height |
| TextElement | 公共字段、type=text、text、style | style 包含 fontSize/color/align/lineHeight/bold，可含 fontFamily/letterSpacing/outline；outline 缺省为关闭 |
| ImageElement | 公共字段、type=image、assetId、fit、crop、role、可选 effects | fit 为 cover/contain；role 为 photo/sticker；effects 定义外轮廓、边缘幅度、边框宽度与颜色 |
| PhotoSlotElement | 公共字段、type=photoSlot、可选 role/effects | 模板中尚未放入图片的占位框，填图时继承效果 |
| Asset | id、name、mime、width、height、bytes | id 为文件 SHA-256；图片原件由本机素材仓库保存 |
| Annotation | id、pageId、elementId、text、status、message | status 为 pending/needsReview/applied/needsInput |

`pages` 数组就是页序，`elements` 数组从底层到顶层排列。没有额外的 pageOrder、elementOrder 或 zIndex。文字直接存于 text，旋转字段叫 rotation，不使用旧设计中的 content.text、rotationDeg 或 fontId。

项目、页面、元素和批注使用稳定 ID；复制生成新的页面和元素 ID，复用图片资产。主题为 paper/live，模板实例化后成为普通页面，不依赖在线模板服务。

## 2. 几何与渲染

- 几何单位为 pt，1 inch = 72 pt。A5 为 419.528 × 595.276 pt；画布缩放不改变文档尺寸。
- 原点在左上角，x 向右、y 向下；旋转围绕元素框中心，正角度顺时针。
- 图片 crop 为归一化矩形 x/y/w/h；先裁取原图区域，再以 cover 或 contain 等比绘制。
- 字号和字间距使用 pt，lineHeight 为倍数。随包提供 Noto Sans SC 和 Noto Serif SC；画布、AI 预检和 PDF 共用页面与文字布局实现。
- visible=false 不显示、不导出；locked 限制编辑，不影响输出。选择框、批注标记和参考线不进入 PDF。
- 背景为页面属性；上传封面图片仍为 image 元素。完整图片封面模式不自动叠加标题和城市文字。

## 3. 人工修改与批注

修改通过有类型的命令进入主进程，检查目标、类型、范围、锁和版本后事务保存。局部字段更新只提交变动字段，避免不同输入框互相覆盖。

批注输入自动保存，支持跨页面收集。修改目标内容或样式后，未完成批注转为 needsReview；用户确认仍适用后才能提交。调整页序不改变目标关联。删除元素或页面时移除对应批注，撤销时随文档恢复；当前格式没有 orphaned 状态或目标指纹字段。

AI 应用成功后标为 applied；缺少信息或超出能力范围标为 needsInput，并保留说明。修改批注可以重新进入待处理状态。

## 4. 用户自带 API

AI 不经过售卖方服务端。用户填写协议、baseUrl、model 和 API Key。支持 Chat Completions、Responses、Anthropic Messages 三类接口；平台必须支持其中一种实际协议，不承诺兼容所有平台的专有接口。

Key 在 Windows 主进程通过 safeStorage 加密保存，不放入纪念册、备份或诊断信息，也不返回界面。更换地址或协议需要重新输入 Key。远程地址要求 HTTPS，本机回环地址允许 HTTP；禁止 URL 凭据、查询参数和片段，禁止自动跟随重定向。

默认只发送相关页面的结构、文字和批注，不发送整本原图。用户可开启图片缩略预览和平台支持的 JSON Schema 输出。连接测试也是一次真实模型请求，可能消耗用户额度；软件不维护平台余额。

## 5. 模型输入与输出

本机内部请求为 `{ taskId, album, previews }`，album 是必要页面与活动批注的快照。每次最多 100 条批注，每组 8 条依次请求；实际发给平台的是尺寸、该组所在页面和批注，可选附带相关素材缩略图。模型无需获得文件路径、数据库位置或 Key。

平台返回 `{ results: [...] }`。每条结果必须包含 annotationId、status、message、changes；status 为 proposed 或 needsInput。changes 必须包含以下所有字段，未修改字段填 null：

| 字段 | 用途 |
| --- | --- |
| x、y、width、height | 元素框位置和尺寸 |
| rotation、opacity | 旋转与透明度 |
| text | 仅文字元素的内容 |
| fontSize、color、align、lineHeight、bold、fontFamily、letterSpacing | 仅文字元素的样式 |
| crop | 仅图片元素的合法归一化裁切 |

needsInput 的 changes 必须全部为 null。软件不从自然语言“已完成”推断成功，不执行脚本，不接受未知字段，不自动切换协议或重试付费请求。

适配器把字段变更转换为目标元素，产生内部提案 `{ baseRevision, results }`。内部结果可包含经过校验的 element；模型没有直接替换整个文档的权限。

AI 不能添加删除元素或页面、改变素材引用或图片 fit、重命名元素、改变可见性或锁状态，也不能修改非批注目标。用户仍可以手动操作这些内容。

## 6. 校验与提交

1. 校验 JSON 结构、字段类型、结果数量和重复或未知批注。
2. 确认任务仍有效、源 revision 一致、目标存在且未锁定。
3. 检查目标类型、允许字段、裁切、数值范围及元素框边界。
4. 在快照副本中试应用，使用本地渲染器检查 AI 文字溢出。
5. 所有分组和预检完成后，一次 SQLite 事务写入结果、批注状态与可撤销历史。

任何请求失败或拟应用结果不合法，整批不提交，原稿和批注保留。needsInput 可与合法方案一起提交，不改变对应元素。不会自动重新生成隐藏的付费请求。

## 7. 任务与取消

AI 运行期间整本纪念册禁止写入，可以浏览或取消。锁由主进程和界面约束；任务对外为 running/succeeded/failed/cancelled，内部 ID 和 AbortController 由本机协调器管理，不使用联网任务队列。

取消先使本地任务 ID 失效，再中止请求；异步返回和提交前再次校验 ID，晚到结果不能写入。任务五分钟超时后失败并解锁。进程重启后任务失效，不自动重新发送；取消不能保证平台退还已消耗额度。

一次 AI 修改对应一个历史步骤，支持前后对比和整体撤销；如之后已有人工修改，需要先撤销后续步骤。PDF 导出固定启动时的快照，期间允许继续人工编辑，但不同时启动 AI。

## 8. 本地存储与版本

SQLite 使用 WAL 和 FULL 同步，保存当前文档、递增 revision 以及正向/反向 JSON Patch 历史。数据库 schema 版本与 Album.schemaVersion 分开管理；旧数据库迁移前备份，已知版本按步骤迁移。

原图按摘要独立存储，缩略图和预览可重建；清缓存不删除原图或撤销历史。工程包为 `.memorybook` 归档，恢复前验证结构、素材摘要、引用与解压大小，不覆盖已有项目。缺少原图或超出限制明确失败。

软件设置与 AI 连接设置独立于纪念册，Key 不随工程包迁移。容量、构建和验收边界见 [开发运行与交付](07-开发运行与交付.md)。
