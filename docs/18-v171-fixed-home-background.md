# 1.7.1：固定首页背景与缩放

首页背景固定在窗口上，滚轮只滚动内容，背景保持静止。背景以窗口大小而非整页内容高度计算，浏览长列表时不会被拉长；调整窗口大小时自动重新铺满。

“设置 → 外观 → 首页背景”新增“背景缩放”，范围 100%–400%。100% 按图片比例自动铺满窗口，继续放大可裁去外围，始终居中，不留空白、不产生横向滚动条。修改自动保存在本机，恢复默认外观时回到 100%。旧设置没有该字段时也使用 100%。

实现采用固定、裁切的背景容器与独立图片层，避免放大背景影响页面的滚动范围。图片沿用本地压缩预览；背景和缩放均不进入纪念册设计或 PDF。

发布仍覆盖 `out/delivery/` 和 `out/Memorybook-Windows-x64.zip`。交付目录中的浏览器缓存、图片预览、日志与临时生成资料可清理，工程数据库、原图、恢复副本、导入字体和自定义短语保留。GitHub 源码不收录本机数据、缓存、API Key 或私钥；分发 ZIP 只含程序文件与公共默认短语，图片和 ZIP 使用 Git LFS。
