# 纸感留白

纪念册的纸张应承托照片，让人先看到回忆，再感到材质。以温暖的灰白、亚麻与浅牛皮纸为底，纹理保持低对比，不用强烈阴影模拟厚重纸边。精细控制线条间距和颗粒密度，使材料在打印尺寸上也显得安静。

棉纸用短小纤维创造疏密变化；宣纸以更细长的纸筋呈现柔软触感。它们不借大幅重复花纹表达材质，留白仍然完整。每一道细线的力度和位置都经过仔细校准，服务于照片和文字的可读性。

方格与点阵是整理记忆的秩序，尺度应足够轻，不与照片边框争夺注意。亚麻用交织的微细线条体现织物感，避免明显棋盘。水彩底使用整页舒展的鼠尾草绿与沙色渐层，不切割成规则色块。

文字选择与纸面保持克制的对比。标题不因背景纹理增加装饰负担，字号、留白和字距承担层级。最终效果以真实画布和导出 PDF 为准，逐页复核材质的分寸、照片清晰度与字形，保持认真推敲后的完成度。
