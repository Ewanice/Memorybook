# 1.4.0 Layout art direction

日期：2026-10-15。将构图、纸张、底色与文字配色作为一套设计更新，继续保持英文软件路径。

## 排版方案

11 套内置排版均提供浅色和深色搭配。浅色以纸白、亚麻、鼠尾草绿和牛皮纸为主；深色在墨绿之外加入蓝灰、暖棕与灰紫。字色区分正文墨色与页眉辅助色，不再全部使用同一种绿。

| --- | --- | --- |
| 留白独白 | 棉纸、深灰绿与暖褐辅助色 | 保留单张主图与大留白，宋体短语形成停顿 |
| 双帧对话 | 亚麻、灰褐与陶土色 | 两张照片错位，文字和贴纸分区 |

| 单张主图 | 宣纸、灰绿文字 | 图、短语与贴纸以统一边距组织 |
| 双图故事 | 水彩晨雾、鼠尾草绿 | 纵向错位双图，下方留出文字空间 |

## 更换背景与文字

页面底色与纸张增加“同步搭配文字颜色”，默认启用。选择纸张时搭配正文与页眉色；调整自定义底色时，只修正对比不足的文字，保留已经清晰可读的自选颜色。可以关闭同步以完整保留手工配色。

锁定文字及主要覆盖在照片上的文字保留原色，避免修改照片上的白色标题。同步改色与换底作为一次编辑保存、撤销；受影响的待处理 AI 批注会标为需要复核。

页码根据当前纸张和底色匹配可读颜色。默认文字在未被图片覆盖的纸面上，基底色对比度不低于 4.5:1；正文方案尽量达到 7:1。此数值针对底色计算，不能保证任意用户照片上的文字可读，因此覆盖文字保留人工控制。

暗色水彩降低明亮色雾的强度，暗色方格和点阵改用低透明度浅色线点；亚麻改为细密织纹，减少大块方格感。纹理继续使用 SVG，与 PDF 共用渲染组件。

## 生成与旧工程

固定排版随机轮用保留每一套自己的纸张与字体颜色。基础照片网格也能排入短语和已选贴纸。自定义排版保持保存时的纸张和字体，不被内置方案强行替换。

Codex 的固定排版目录增加纸张、底色和文字样式信息，模型可以根据完整方案选排版。自由设计明确沿用封面纸张及底色，并据此选择字色；本次不额外改变生成 JSON 的必需字段。

新建工程或主动重新套用排版时使用新版构图。已有页面的布局、底色与文字色不自动重写；同名纸张的渲染细节随版本改进。

## 验证与交付
