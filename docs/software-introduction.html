把回忆排成一本书

拾页是一款 Windows 离线纪念册设计软件。放入自己的照片、贴纸和短语，生成多页排版，逐页调整，再导出 PDF。

先排好，再慢慢改

适合演唱会留念、旅行记录、毕业纪念与日常相册。先得到一本完整初稿，再把每页改成自己喜欢的样子。

用你自己的素材

照片、贴纸、文字都能独立编辑，封面也由你决定。

  • 照片与贴纸：JPEG、PNG、WebP
  • 短语：在软件中编辑，也可修改根目录 phrases.txt
  • 字体：导入可嵌入的 TTF / OTF 字体
自动混排，也能自建模板
内置多套照片、短语与贴纸排版，生成时随机轮换使用；也可在排版编辑器中制作自己的模板。
封面与内页一起设计
上传封面图，填写主题标题与城市角标；每页可切换纸张、底色，按需添加页码并设置位置。
每个元素都能继续调整
拖动、缩放、旋转照片与贴纸；修改文字内容、字体、大小和颜色。支持多选、组合、对齐与撤销重做。
先批注，再统一 AI 修改
对多个页面的元素分别写下修改意见，再点击“统一 AI 修改”。等待时暂时锁定编辑，可取消任务，完成后查看前后对比。
逐页 PDF，工程也能保留
一个设计页面对应一页 PDF，方便分享与打印；另存 .memorybook 工程备份，后续可导入继续编辑。

从照片到纪念册

普通排版不需要配置 AI。先用固定排版完成第一本，再按需尝试 AI。

  1. 解压完整的软件文件夹

    在有写入权限的英文路径下解压，例如 D:\Memorybook，打开 Memorybook.exe。首次使用按提示填写随发布包提供的卡密。请保留同目录的配套文件。

  2. 准备照片、贴纸和短语

    在首页贴纸库导入自己的贴纸，在“设置 → 短语库”整理文字。照片在新建纪念册时选择。

  3. 新建纪念册，生成第一版

    点击“新建纪念册”，填写标题、角标，选择照片及本次想使用的贴纸，确认尺寸、排版和页码。选择固定排版即可直接生成。

  4. 逐页调整，或让 AI 帮忙

    点击元素，在右侧调整属性；双击照片进入裁切，双击文字定位文字编辑。需要 AI 时，先在设置中配置自己的 API 或本地 Codex，再使用生成或批注修改。

  5. 检查页面，导出与备份

    点击“导出 PDF”，根据提示检查缺失素材、分辨率与文字溢出。设计过程会自动保存；迁移电脑或保留一个版本时，再导出工程备份。

使用前了解这些

不联网也能用吗？

可以。导入素材、固定排版、手动编辑、保存和 PDF 导出均可离线完成。主动调用 AI 时需要连接相应服务；发送给服务的内容以所选功能为准。

AI 需要额外付费吗？

软件不包含 AI 额度。API 模式使用你在服务商购买的额度，填写对应接口地址、模型与 API Key；支持情况取决于接口协议兼容性。本地 Codex 模式需要电脑已安装并登录可用的 Codex，按其账户与额度规则使用。

照片和工程存在哪里？

默认在软件目录的 data 中保存工程与导入素材；短语库为根目录 phrases.txt，字体与配套素材位于 materials。移动软件时保留完整目录，并为重要工程另存备份。PDF 用于分享，工程备份用于继续编辑。

我需要会设计或编程吗？

不需要。先导入自己的素材，用固定排版生成，再调整不满意的部分即可。AI、排版编辑器和高级设置都可以之后再用。
