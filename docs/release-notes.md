拾页 / Memorybook 1.8.0

新增“设置 → 关于 → 检查更新”。软件不主动检查或提示新版本，仅在手动检查和下载时联网。

- 下载和准备可取消，期间可以继续编辑；准备完毕再重启更新。
- 优先使用二进制差分补丁，旧文件不匹配时使用完整更新内容。
- 独立更新窗口支持取消与回退，新版启动失败或更新中断时恢复原程序。
- 更新只替换程序，不覆盖工程、照片、贴纸、导入字体、个人短语和共享设置。
- 更新源由软件根目录 update-source.json 配置，支持 GitHub Release 或静态 HTTPS 托管；配置不会随更新覆盖。
- 更新清单采用 Ed25519 签名，补丁、下载和重建文件均校验 SHA-256。

1.7.3 及更早版本首次需手动解压覆盖到 1.8.0，之后可使用软件内更新。请保留完整软件目录中的 Memorybook.exe 与 Memorybook.App.exe。
