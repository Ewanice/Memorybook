## 保存与迁移

正式版默认以 Memorybook.exe 所在的完整软件文件夹为根目录。解压到 D:、E: 等可写位置即可使用；没有写入权限时应更换解压位置，不会静默切回 C: 用户目录。

| 内容 | 软件根目录下的位置 |
| --- | --- |
| 工程、设置、授权、贴纸库和排版库索引 | 数据/memorybook.sqlite |
| 导入照片与贴纸原件 | 数据/assets/文件摘要 |
| 可重建预览 | 数据/previews |
| Chromium 本地缓存和日志 | 数据/浏览器缓存、数据/日志 |
| Codex 工作目录 | 数据/codex-generation |
| 明文短语库 | 短语库.txt |
| 导入 TTF/OTF 字体 | 素材/导入字体/文件摘要 |
| 随软件提供的字体与纸张素材 | 素材/内置字体、素材/纸张 |

导入原图按 SHA-256 去重；相同文件不会额外复制，也不会重压缩原件。图库移出操作只更改索引，不破坏已有工程引用。设置 → 文件与导出 → 查看实际保存位置展示当前运行实例的路径。

首次升级时，目标目录尚无数据库且旧系统用户目录存在数据库，会用 SQLite 一致性快照复制数据库并复制原图；最后才启用目标数据库。旧目录保留，不自动删除，也不复制旧 PNG 预览。迁移可中断重试，已有目标工程不覆盖。旧版软件旁的短语库需要保留；更新时不要用随包的默认短语覆盖自己的文本。

开发构建默认使用工程目录 .local/user-data。开发隔离变量 MEMORY_USER_DATA 与显式 --user-data-dir 用于测试或明确选择数据位置，优先于默认路径；它们不是自动退回系统盘的策略。系统临时目录与本机 Codex 自己维护的账号、模型缓存不属于本软件素材目录。

## 缓存

- 缩略图最长边 240 px，编辑预览 1440 px，分享导出预览 1200 px，不放大小图。
- 不透明图片生成 JPEG（缩略质量 78，其他预览 84）；透明贴纸保留 PNG，逐像素检查 alpha。
- 同一图片和规格的并发请求合并；同时最多处理两个预览，减少大图集中解码占用。
- 预览目录按最近使用时间近似淘汰到 256 MB；在途预览暂不删除。时间戳至多每日更新一次。旧 PNG 缓存在生成新预览时清理。
- 资源响应不另存一套浏览器磁盘副本。设置可清理预览缓存，原图、工程和字体不删除；AI 或导出任务运行时不清理。
- 本次合成照片样例原图 2,565,307 字节，编辑预览 183,566 字节，减小约 93%；该比例只代表本次样例，不承诺所有照片相同。
- 高清 PDF 始终使用原图。纸张使用轻量 SVG 图形，不为每页生成大幅位图缓存。

## 首页与快捷键

首页右上角显示 Codex 检测中、已连接、待登录、未连接，点击进入设置；约每 30 秒刷新本机连接状态，不请求模型生成。默认窗口高度由 960 调至 1080，并限制在显示器工作区内；缩短首页卡片与留白，顶部保留“贴纸 · 短语 · 排版 ↓”入口。

| 快捷键 | 纪念册编辑、排版编辑 |
| --- | --- |
| Delete | 删除选中元素 |
| 方向键 | 微调 1 pt |
| Shift + 方向键 | 微调 10 pt |
| Ctrl + D | 复制选中元素并偏移 |
| Ctrl + Z | 撤销 |
| Ctrl + Y / Ctrl + Shift + Z | 重做 |
| Esc | 取消选中 |

在文本输入、下拉框内保留原生键盘行为；锁定元素不能删除、移动，AI 执行期间禁止设计修改。纪念册快捷键历史操作与保存队列串行，避免连续操作发生版本冲突；排版编辑器具有本地撤销和重做历史。项目继续自动保存，排版仍需点击保存排版。

## 逐页底色

右侧属性的“页面底色与纸张”始终可用，选中元素后也能调整。提供纯色、棉纸、云絮宣纸、暖调牛皮纸、亚麻织纹、手帐方格、点阵笔记、水彩晨雾；纹理可再搭配自定义底色。修改只影响当前页并进入撤销历史。自定义排版也保留纸张样式。

视觉方向沿用 canvas-design 的留白与材质思路：低对比纹理不抢照片，方格和点阵保留呼吸感，水彩铺成缓慢过渡的色雾，避免机械重复斑块。预览见 [纸张背景预览](纸张背景预览.png)。

Page 新增可选 backgroundStyle，background 仍为六位十六进制底色。旧工程缺省时按原纯色渲染。编辑画布、缩略预览与 PDF 使用同一个 PageBackground 组件，参数化 SVG 输出保持清晰。

## 字体

设置 → 字体库支持多选导入 TTF、OTF，单文件上限 32 MB；识别真实 SFNT 目录、名称与嵌入限制，拒绝损坏文件、集合文件和禁止嵌入/子集化的字体。字体按 SHA-256 去重，不安装到 Windows 系统字体目录。

文字属性显示导入字体的真实名称；实际引用为 MemoryFont_加文件摘要，避免同名字体冲突或任意 CSS 注入。Chromium FontFace 负责字形解码与排版；文字测量、画布、版式预检和 PDF 使用同一字体。缺字可由内置思源黑体补齐，用户应在预览中确认字形效果。

可编辑工程包新增 fonts/摘要 文件，仅包含实际使用的导入字体，计入 512 MB 解压总量限制；导入时重新验证字体与摘要。内置字体不重复写进工程包。导出 PDF 嵌入实际使用字形；本次已检查 Arial 的 PDF 嵌入与文本可提取。

## 构建交付

运行 npm run package 生成 Electron 完整目录，npm run make 同样调用目录打包，不再生成 Squirrel 安装程序。正式包保留 EXE、DLL、locales、resources 和素材文件夹；字体与纸张在 ASAR 外部的根目录素材文件夹内。

验证后运行 npm run delivery，生成 out/delivery/1.3.0 和 拾页-1.3.0-Windows完整文件夹版.zip。ZIP 使用流式压缩，附统一卡密、快速上手、逐文件 SHA-256。排除用户数据、导入字体、私钥、源码和开发卡密。买方必须完整解压后启动 Memorybook.exe，不可只复制 EXE。

更新时关闭软件，保留 数据、素材/导入字体、短语库.txt，将新版本程序文件替换到原目录。整目录备份包含本地资料；跨电脑迁移建议使用工程备份，AI Key 在新电脑重新填写。
