## 1. 产品与交付决定

- 首发 Windows 11 x64 完整文件夹版，其他系统后续评估，不在商品页承诺未经测试的系统支持。
- 编辑、素材导入、模板、保存和 PDF 导出全部在本机运行，不要求登录。
- 软件仅在用户主动调用 AI 时联网；不自动联网激活、检查更新、同步项目或上传统计与崩溃日志。升级由用户从发货渠道重新下载安装包。
- 平台下单 → 自动发货“云盘链接 + 提取码（如有）+ 简短说明” → 下载并安装 → 打开软件 → 开始制作。
- 云盘下载和购买平台本身需要网络；“离线”指软件下载完成后的安装与基础使用。
- 基础编辑授权默认当前大版本永久使用，不设置依赖本机时间的到期校验。AI 由用户自带 API Key，费用由用户自己的平台账户承担，AI 不可用不影响离线功能。
- 所有用户打开即可使用；平台采用固定发货内容，不维护授权库存或激活服务。
- 直接按完整商业产品架构实现，不交付 MVP 或演示替身。阶段仅用于实施排序和质量验收，不降低正式范围与可靠性要求。

## 2. 交互简化

新建仅三步：选照片 → 选风格 → 生成。主题和城市可在封面直接点选填写；默认 A5、标准密度、推荐页数，不要求新手先理解尺寸和排版参数。

进入编辑器后默认只显示页面缩略图、画布和所选元素常用操作：

| 对象 | 首层操作 | “更多”中提供 |
| --- | --- | --- |
| 照片 | 换照片、调整画面、拖动与缩放 | 旋转、精确尺寸、透明度、层级 |
| 贴纸 | 换贴纸、拖动与缩放、删除 | 旋转、透明度、层级 |
| 文字 | 改文字、字号、颜色 | 字体、行距、对齐、精确尺寸 |

“素材”和“模板”用抽屉按需打开，不同时堆叠多个面板。批注在元素旁点击“让 AI 修改”打开；输入自动保存，统一修改入口显示待处理数量。保持“只改一个元素也不费力，改很多元素也不必重复提交”。

日常制作不显示数据库、授权算法、模型参数、DPI 或几何坐标。导出默认“高清 PDF”，高级选项折叠。保留撤销和自动保存状态，避免通过简化界面隐藏重要反馈。

## 3. 技术选型

| 模块 | 方案 | 选择原因 |
| --- | --- | --- |
| 桌面外壳 | Electron，发布时选择仍受支持的稳定版本 | 内置 Chromium，安装与渲染不依赖在线下载运行时；便于一致导出 PDF |
| 界面 | React + TypeScript + Vite | 适合属性编辑、页面导航、批注与复杂状态；所有资源本地打包 |
| 页面引擎 | 结构化场景树 + 自有 SVG 渲染层 | 图片、裁切、文字、旋转、贴纸和形状复用同一几何模型；不依赖在线设计服务 |
| 数据与校验 | TypeScript 类型 + JSON Schema / Ajv | 对工程、IPC 和 AI 操作做运行时校验；不只依赖编译期类型 |
| 本地保存 | SQLite 事务 + 本地素材目录 | 存项目快照、历史、批注和任务，素材按内容摘要去重；事务保证修改整批应用 |
| PDF | 隐藏导出窗口 + Chromium printToPDF | 复用页面引擎，指定物理页尺寸，保持中文排版与编辑预览一致 |
| 安装发布 | Electron Forge + Windows 完整目录包；代码签名可选 | 默认按未签名包交付；不设置卡密 |
| 使用入口 | 直接打开软件 | 无卡密、无激活，不需要账号或授权服务 |
| AI | 本地任务协调器 + BYOK 多协议适配器 | 用户自填平台地址、模型和 Key；直接请求平台，不建设自营 AI 服务端 |

具体依赖版本和 SQLite 驱动在首个技术原型中锁定；原生模块必须针对打包的 Electron ABI 构建并做干净机器安装测试。不在产品文档中凭空指定未来可用的版本号。

Electron 体积比使用系统 WebView 的方案大，这是接受的取舍：首版更重视安装后断网可用、字体布局和 PDF 一致性。它本身不是防破解技术。

## 4. 本机架构与文件

```text
React 编辑界面（无 Node 权限）
       │ 受限 IPC：打开项目 / 提交编辑 / 导出 / 提交 AI
       ▼
Electron 主进程：本地文档服务、许可证校验、任务协调
       ├─ SQLite：版本、历史、批注、锁、任务状态
       ├─ 项目目录：原图、缩略图、字体引用
       ├─ 导出工作进程/窗口：固定版本 → PDF
       └─ BYOK 适配器 → 用户配置的 AI 平台（仅主动调用）
```

项目默认保存在用户可写数据目录，与安装目录分离。自动保存合并高频拖动，但每次完成的编辑动作必须可恢复；界面只有收到持久化确认才显示“已保存”。

提供“备份工程”生成 `.memorybook` 文件，内容为 manifest、album.json、素材及许可允许打包的字体。导入检查格式、文件大小、摘要和路径，禁止 ZIP 路径穿越；缺失素材明确提示。备份不包含API Key或私人日志。正常卸载默认保留项目。

素材先写临时文件并原子改名，再提交数据库引用。崩溃后清理无引用临时文件；历史和导出快照仍引用的素材不能回收。工程迁移前自动备份，软件升级不覆盖用户项目。

## 5. 编辑与导出实现重点

SVG 仅为内部渲染格式，首版仍不开放任意 SVG 上传。场景树只产生受控元素；用户文字必须转义，用户图片不得转成可执行 HTML。

中文文本由共享文字布局模块测量和断行，输出明确的行与基线，编辑和导出使用相同本地字体、字号和行距；不要让导出端重新猜换行。输入时使用浮层文本框，完成后写回结构化内容。

导出窗口只加载本地代码和指定快照；等待字体就绪与图片解码完毕后打印。每页设置固定纸张尺寸与分页，关闭浏览器页眉页脚，开启背景输出。预设通过图片重采样和压缩控制体积，不把提高输出参数说成提升原图清晰度。

100 页工程以分页渲染和分批导出控制内存，必要时用本地 PDF 库合并分批结果。首个原型验证透明图片、中文字体嵌入、文本可选、裁切、旋转、页数与物理尺寸；不通过前不承诺正式售卖质量。

## 6. AI：用户自带 API Key，直接请求平台

不建设自营 AI 服务端，不售卖 AI 额度，不维护平台账户、兑换凭证或应用内计费。用户在设置中填写 API Base URL、模型 ID、API Key 和协议；软件主进程直接请求该地址，模型调用费用由用户自己的平台账户承担。

支持 OpenAI 兼容 Chat Completions、OpenAI 兼容 Responses、Anthropic Messages 三种协议。这里的兼容指请求和响应协议匹配，并非宣称任意平台、任意模型都能工作；需要非标准签名、OAuth、特殊 SDK 或私有协议的平台需新增明确适配器。提供真实“保存并测试连接”，不自动换协议或重复付费请求。

默认只发送批注、相关页面文字和元素结构。用户明确开启“发送照片缩略预览”后，才附带被批注图片的本地缩略图；模型须支持视觉输入。用户素材、批注均是不可信数据，不能改变系统操作权限。关闭严格结构化输出时使用 JSON 提示约束并本地校验，开启时按平台协议发送 JSON Schema。

Key 使用 Windows 本机凭证加密能力保护，与普通设置、工程和日志分开；不回传到渲染界面，不进入诊断或备份。Key 与规范化 API 地址和协议绑定，更换地址/协议须重新输入该平台 Key。只修改模型可保留 Key。远程地址必须 HTTPS，仅本机回环地址允许 HTTP；禁止 URL 内账号、查询参数和片段，禁止重定向，防止 Key 被带往其他地址。不会通过本产品的服务器中转。

任务在本机快照并加全书写锁；批注按最多 8 条组成模型请求，一次任务的全部方案收齐后统一校验与提交。每次提交最多 100 条批注，界面应在提交前说明超限。AI 不能替换原图、增加或删除元素；只允许修改授权目标的几何、文字、样式与裁切。结构、版本、权限、字体和文字溢出校验失败时，整批不应用。

本地取消先使任务 ID 失效并解锁，再中止 HTTP 请求；不等待平台确认。取消、失败或网络中断不能保证平台退回已产生的费用，软件不承诺退款。应用重启后中断任务失效，保留原稿和批注，不自动重发付费请求。无自动重试与未经用户授权的后台请求。

编辑、备份和 PDF 导出均不依赖 AI 配置。余额、账单、Key 额度与地区限制以用户所选平台为准，本软件不伪造统一余额查询。

## 7. 安全与发布

渲染进程启用沙箱与 contextIsolation，禁用 nodeIntegration；使用受限 preload 接口，验证 IPC 发送者、参数及文件访问范围。禁止任意远程导航与执行，使用严格 CSP 和本地资源协议。以上按 [Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security) 落实。

发布构建启用适用的 ASAR 完整性校验及配套 fuses，关闭不需要的 Node 启动与调试入口；发布包不附源码映射。ASAR 只是打包格式，完整性检查和混淆都不能保证不可破解。参考 [ASAR Integrity](https://www.electronjs.org/docs/latest/tutorial/asar-integrity) 与 [Electron Fuses](https://www.electronjs.org/docs/latest/tutorial/fuses)。

软件不再使用卡密与授权签名密钥。按当前要求，Windows 代码签名证书为可选项，默认生成未签名完整目录包；可能显示未知发布者或系统信誉提示，软件仍可离线使用。以后若配置代码签名，同时签安装程序与可执行文件。签名不能保证杀毒或 SmartScreen 永不提示，更不等于商业许可证校验。参考 [Electron Code Signing](https://www.electronjs.org/docs/latest/tutorial/code-signing)。

发布检查依赖、字体、模板和装饰素材许可，提供必要声明；不要将“可免费下载”直接等同于可随收费软件再分发。更新包仍通过云盘交付；离线旧版本不因停止 AI 服务而失效。

## 8. 技术验收门槛

1. 干净 Windows 测试机下载后断网：解压、打开、生成、编辑、保存、重开、导出全部成功，不缺运行时和字体。
2. 未调用 AI 时无应用主动网络访问；断网调用 AI 只提示联网需求，不影响已保存项目。
3. 全新目录首次打开直接进入首页；旧版遗留的卡密字段不影响工程读取与编辑。
4. 100 页工程和大图场景不缺页、不丢资产；崩溃、磁盘满、升级后仍能恢复已确认保存的数据。
5. AI 运行只读；断网取消立即恢复本地编辑；晚到结果、重复响应、应用重启均不覆盖新版本。
6. 不同订单自动发送相同完整软件包与说明；首次启动及升级均不要求卡密。

技术验证参考：[printToPDF API](https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions)。官网资料于 2026-10-15 查阅，正式编码时再次核对选定版本。

## 9. 正式架构与代码质量约束

采用模块化单体桌面应用，AI 使用用户自带 Key 直连；不因“商业级”而增加没有实际需求的微服务、通用插件系统或多套持久化后端。技术验证可以先做，但正式路径必须使用真实模块和数据契约，不把临时 mock、演示数据或假成功带入发布构建。

| 层与模块 | 职责与依赖边界 |
| --- | --- |
| domain | 场景树、编辑命令、版式约束、版本与差异；不依赖 React、Electron、数据库和网络 |
| application | 项目、历史、导出、AI、设置用例及任务状态机；通过显式接口调用存储、渲染和外部服务 |
| infrastructure | SQLite 事务、文件资产、迁移、PDF与 AI 网络实现；不直接操作 UI |
| desktop / preload | 进程生命周期、受限 IPC、权限与单工程写锁；不向界面暴露任意文件、SQL 或网络能力 |
| renderer | 页面与控件、暂存输入和选择状态；不维护另一套持久化事实，不直接修改数据库 |
| delivery | 完整包校验、发货说明与技术服务配置 |

接口以实际边界为依据抽象，不为每个函数创建无意义包装层。所有写入经过统一用例与事务；人工编辑和 AI 修改共用命令校验及历史机制。持久化格式、IPC 和 AI 输入输出有显式版本与运行时验证，升级迁移有备份和失败恢复。

“不写无意义托底代码”具体要求：

- 不用空 catch、返回空数组或伪造默认文档掩盖读写失败；不把失败打印成警告后继续显示成功。
- 字体缺失、项目损坏、AI 结构非法时明确中止相应操作并报告原因，不静默换字体、重建空项目或假装完成修改。
- 不为未知旧版本添加猜测性兼容、不用多条重复执行路径增加不确定性；仅实现已明确支持版本的迁移。
- 保留有明确目的的可靠性措施：输入验证、事务回滚、原子写入、备份、取消、幂等、有限重试和可重建缓存。这些不是无意义托底，每项需有明确触发条件、退出条件与验证场景。
- 只对可识别的暂时性错误有限重试；鉴权失败、数据校验失败不自动重试。副作用重试必须先满足幂等，禁止无限循环或重复扣费。

质量门槛包括严格类型检查、静态检查、领域规则与故障路径测试、跨模块集成测试、真实安装包端到端测试、依赖许可与安全检查。重点验证保存恢复、直接启动、AI 取消竞态、迁移与导出一致性，不以堆积无意义测试数量代替可靠性。

## 10. 设置的数据与实现边界

新增独立的版本化 AppSettings，不与 Album 混存。存储界面缩放、辅助线和吸附默认值、新项目尺寸、PDF 质量、导出目录及 AI 启用状态；产品规则见 [PRD 第 9 节](01-产品需求文档.md#9-必要设置与默认行为)。设置经主进程验证并事务持久化，成功后才通知界面更新。改变新建默认值不改现有工程。

API Key 加密存储，不进入普通设置 JSON、工程包或日志。设置迁移保留用户值，未知字段和无效值不得静默覆盖合法配置；首次安装才使用完整默认配置。损坏配置提供明确诊断及经用户确认的重置，保留损坏副本，不悄悄装作首次使用。

缓存清理通过专用接口，仅删除索引登记且确认可重建的缓存；与导出和预览任务协调，避免删除正在使用的资源。恢复设置不删除项目、原图、历史、许可证或 API Key。AI 任务运行中关闭 AI 按取消流程先使本地任务失效，再关闭网络访问，防止晚到结果写入。

目录不可写、磁盘满、设置写入失败均保留先前有效状态并返回可理解的错误；不静默改用临时目录。诊断导出由用户主动操作，在写出前剔除素材内容、凭证，禁止后台遥测。
