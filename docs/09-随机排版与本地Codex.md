# 1.2.0：随机排版、库编辑与本地 Codex

2026-10-15。本文更新 1.1.0 的单选/交替生成方式，当前实现以本文为准。

## 使用方式

- 首页进入“排版库”：预览全部内置照片排版，复制内置排版编辑，或新建自己的排版。保存后自动参与生成，删除不影响已有纪念册。
- 新建不再单选一套：全部可用于照片的排版一起进入随机池，每轮打乱后轮用；照片不足时无需强行用完全部。空白页与尾页保留为手动页面，不用于自动照片分组。
- 首页“编辑短语库”或设置中的“短语库”：软件内直接编辑，一行一句，保存到同一个明文文件。保留外部文件位置和重读入口，检测外部修改冲突，不覆盖已生成文字。
- 新建时勾选“添加页码”，或编辑器点击“页码”：支持六种上下左右/居中位置及起始编号，封面封底不计入；内页重排后自动更新，PDF 与画布一致。
- 生成方式选“本地自动排版”或“调用本地 Codex”。前者完全离线，后者复用本机 Codex 配置和登录，通常需要联网并消耗对应额度。

## 排版编辑器

复用实际纪念册画布及元素属性，可添加照片位置、贴纸位置、短语位置和固定文字。支持拖动、缩放、旋转、颜色、字体、位置与图层调整，以及草稿撤销。文字可切换为短语占位或固定内容；复制短语元素保留占位语义。

自定义排版最多 50 个，每套至少包含一个照片位置、最多 100 个元素。保存时检查 ID、引用、类型、边界和真实字体下的文字溢出，不保存原始照片，不执行排版脚本。跨 A5/方形实例化按比例缩放，生成后所有内容仍为普通可编辑元素。新建使用当前保存版本，不改变已有工程。

短语仍以 UTF-8 `短语库.txt` 存储，保留一行 80 字符、1000 行和 512 KB 限制。软件内保存前先校验，再检查文件摘要和写入；文件被其他程序修改时提示重新读取。合法 UTF-8 的超长句可以先载入编辑器修复。默认示例仍为原创短语。

## 本地 Codex 连接

使用 [OpenAI 官方 App Server 协议](https://learn.chatgpt.com/docs/app-server)，由主进程启动本机 Codex 的 stdio 连接，不需要售卖方运营服务器，也不要求复制 Codex 的登录令牌到本软件。自动检测可执行文件、读取登录状态和可用 skill；自动检测不发送生成请求。

Windows 优先从 PATH 和 Codex 桌面版安装位置检测；设置中也可选择 codex.exe、填写模型 ID、编辑默认提示词并选择最多五个本地 skill。未找到或未登录时提示原因；本地自动排版与 BYOK 批注仍可独立使用。不会安装 Codex、购买额度或自动登录账号。

固定排版模式由 Codex 选择给定排版、分配照片与短语，软件负责实例化。自由设计模式可返回照片/贴纸/文字的几何，提供最多八张本地缩略图；skill 只用于设计参考。默认提示词提供照片主导、边距、层级、留白、顺序、素材完整性和结构输出要求，可在设置恢复或修改。

连接创建独立临时生成会话，不读写用户其他 Codex 对话。生成仅接受结构化 JSON：固定排版 ID 必须来自当前库；照片不得遗漏、重复或越权引用；自由元素必须满足类型、素材、几何和文字约束。Codex 使用只读沙箱，不获得本地纪念册数据库写权限。软件验证和版式预检全部通过后才创建工程。

生成期间新建表单暂停编辑，显示进度，支持取消，十分钟超时。取消立即使本地生成失效并尝试中断对应 turn；晚到结果不创建工程。失败不自动改为本地生成，不应用半套结果，也不会由软件自动重发付费请求；Codex 自身的连接恢复会在状态中说明，已消耗额度不保证退回。

逐元素 AI 批注继续使用原有 BYOK，不在本次改动中切换到 Codex。

## 数据与模块

- `domain/layouts.ts`：排版定义、实例化、随机轮用；`layout-validation.ts` 在主进程校验，避免把动态 JSON Schema 编译器带入沙箱界面。
- `domain/edit-core.ts`：共享纯编辑规则，主进程 `edit.ts` 包装完整运行时校验；模板草稿复用纯规则，保存必须经主进程复核。
- `Album.pagination`：可选页码配置；旧工程缺省关闭，无需破坏性数据迁移。页码属于派生渲染，不写成会随页序过时的普通文字。
- SQLite 的 `layout-library`、`codex-preferences` 独立保存自定义排版与连接偏好，不保存 Codex 凭据。
- `codex-bridge.ts`：本地进程、JSONL、请求响应、事件、技能与取消；`GenerationCoordinator`：快照、任务状态、超时、失效与提交；`generation-plan.ts`：模型结构及素材权限校验。

本机可验证的安装与登录不代表买方机器均已安装 Codex；旧版协议、用户自选模型、插件与账号额度可能不同，需在设置检测。另一台干净 Windows 的安装/卸载及售卖平台发货仍属于上线前人工验收。
