## 1. 当前实现

1.3.0 的保存、缓存、纸张、字体和完整文件夹交付规则见 [本次更新](10-软件目录存储与纸张字体.md)。原图、工程与缓存默认位于软件根目录的 data，导入字体与内置素材位于 materials，短语库直接位于根目录。

1.2.0 新增软件内短语库编辑、自定义排版编辑器、全部排版随机轮用、动态页码和本地 Codex 生成。配置、协议与当前使用规则见 [1.2.0 更新](09-随机排版与本地Codex.md)。

Windows x64 离线桌面应用，打开即可使用，无需卡密或激活。支持照片与透明贴纸导入、照片封面/完整封面、标题与城市文字、两套配色、多种内页模板、可填充照片槽、全部排版随机轮用、拖动页序、封底、项目复制和重命名。

元素支持移动、缩放、旋转、裁切、图层顺序、锁定和复制删除；文字支持本地黑体/宋体、字号、颜色、对齐、行距、字间距与内容编辑。模板套用需确认替换，支持撤销。空的照片或贴纸占位不能直接导出。新增四套固定构图、首页贴纸库、软件目录明文短语库，详见 [排版与素材库](08-四套固定排版与素材库.md)。

SQLite 保存工程、批注及增量撤销历史，已知旧数据库格式升级前备份；导出固定版本的逐页 PDF，可同时继续人工编辑。工程包可备份和导入，资产按摘要验证。缩略图和页面预览本地生成，缓存清理不删除原图和工程。

元素批注 AI 采用 BYOK，直连用户配置的平台，支持 Chat Completions、Responses 和 Anthropic Messages。API Key 本机加密且绑定地址；跨页批注统一提交，任务期间整本只读，可取消，结果整批应用并支持持久化对比与撤销。非标准接口需明确增加适配，不会遇错自动换接口、编造成功或自动重试付费请求。

设置包含界面缩放、辅助线与吸附、新建默认尺寸、导出质量与目录、缓存管理、AI 配置和连接测试、版本、第三方许可、诊断预览与导出、恢复默认设置。高级项按需展开。

## 2. 工程结构

| 目录 | 职责 |
| --- | --- |
| src/domain | 场景树、模板、编辑规则、运行时校验与文字布局 |
| src/application | 项目用例、任务锁、AI 编排与结果校验 |
| src/infrastructure | SQLite、JSON Patch 历史、素材与缓存、BYOK、加密配置及版式预检 |
| src/desktop | Electron 主进程、受限 preload 与安装事件 |
| src/renderer | 编辑界面、模板、设置、共享 SVG 页面及隔离导出引擎 |
| scripts | 构建、集成测试、发布包验证与交付整理 |
| tests | 领域与持久化、三协议转换、Key 绑定、取消竞态及迁移测试 |

依赖通过 package-lock.json 锁定。Node 24 的内置 SQLite 随 Electron 运行时提供，不依赖买方机器安装 Node 或数据库。字体为随包分发的 Noto Sans SC / Noto Serif SC，许可汇总在应用“第三方许可”中。

## 3. 构建与交付

开发安装依赖后执行 npm run build 和 npm run dev，不再需要生成密钥或卡密。

```powershell
$env:MEMORY_RELEASE = "1"
npm run package
npm run verify:release
npm run delivery
```

正式构建开启生产压缩与完整性保护，关闭开发调试入口；无需 MEMORY_PUBLIC_KEY 或签发步骤。完整包位于 out/Memorybook-Windows-x64.zip，包含程序目录、README.txt 和 SHA256.json，不再包含 license.txt。

如需 Windows 发布者签名，可另外配置 MEMORY_SIGN_CERT 与 MEMORY_SIGN_PASSWORD；当前不配置证书也可以构建。发布包不包含用户工程、个人素材库、API Key 或开发资料。

## 4. AI 设置

1. 在设置中开启“允许主动使用 AI”。
2. 选择平台实际支持的 API 协议，填写基础地址及模型 ID。
3. 输入自己的 API Key，点击“保存并测试连接”。测试会实际调用模型，可能产生平台费用。
4. 模型支持图片时可开启缩略预览；平台支持 JSON Schema 时可开启严格输出。
5. 选择元素填写批注，跨页收集后点击“统一 AI 修改”。

Base URL 填到接口基础路径，例如包含 `/v1` 时保留该部分；不要再追加 `/chat/completions`、`/responses` 或 `/messages`。不要在 URL 内填 Key。远程 API 使用 HTTPS，本机回环代理可用 HTTP。网络错误、额度不足和模型能力不匹配会明确失败，原稿保留；费用与退款由对应平台决定。

软件不内置服务商 Key、不运营 AI 网关、不统一售卖额度、不承诺读取各平台余额。连接设置和 Key 不随工程包迁移，换电脑后重新填写。

## 6. 当前容量边界与发布前检查

- 单张图片不超过 25 MB，最大 10000 万像素；工程最多 100 页、每页 100 元素、最多 1000 个资产记录。
- 单次新建最多选择 500 个资产；实际能生成的页数取决于密度，超过 100 页会提示调整，不悄悄丢图。
- 当前工程包备份和导入的解压总量上限为 512 MB；大工程可继续本地编辑和 PDF 导出，但不能超出该工程包限制。后续如调整该限制需先改为流式归档并验证内存。
- 一次 AI 任务最多 100 条活动批注，分组请求；任何请求失败不应用半套结果。设置中关闭 AI 或更换连接配置会取消当前本地任务。
- 字体变化、图片裁切、旋转与透明贴纸须在目标打印尺寸下复核。PDF 文本可选择；部分相同 CJK 字形的 Unicode 提取需 NFKC 规范化，视觉渲染已检查。
- 发布前使用真实照片和另一台干净 Windows 机器复核安装、卸载、打印及内存；核对店铺品牌、云盘下载、自动发货与售后信息。

## 7. 买方交付

将 `out/Memorybook-Windows-x64.zip` 上传云盘，或整理 `out/delivery/`。内含完整 Memorybook 文件夹、快速上手和文件校验值。买方完整解压后运行 Memorybook.exe，无需安装或激活。自动发货提供云盘链接、提取码（如有）和使用方法。工程源码、`.local/`、私钥、测试数据和工具链均不上传。

购买/下载需要网络；安装后可断网编辑、保存和导出。只有主动测试 AI 连接或提交 AI 修改时，软件才请求用户配置的平台。未签名版本可能显示未知发布者，商品说明应如实写明。
