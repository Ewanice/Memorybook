# 纸上节奏

照片是这本纪念册的主角，纸张是承托它的安静空间。构图以统一边距和明确的照片区建立秩序，再用错位、留白与小幅旋转改变阅读速度。每一种变化都经过细致调整，避免用杂乱装饰制造热闹。

材料的差异应当能被感知，又不抢夺内容。棉纸与宣纸服务独照，亚麻适合双帧，方格承载现场手记，牛皮纸留下票根与来信。纤维、网格和色雾分别采用合适密度，在实际打印尺度上推敲分寸，不把页面铺成醒目的纹理图案。

墨色随材料变化。暖纸用深褐，浅绿用植物墨色，深蓝灰用柔和的浅灰。页眉小字承担定位，宋体短语留下一点手写书信般的停顿。通过精确的对比与字号安排形成层次，而不是不断增加颜色。

整本的节奏由密与疏共同形成：单图之后可以接索引，规整网格之后可以接一封拼贴来信。照片、短语与贴纸都有自己的位置，边界经过认真校准。设计最终落实在可编辑的元素上，并以真实画布和 PDF 验证完成度。
