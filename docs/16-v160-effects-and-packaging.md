# 1.6.0：文字描边、图片效果与覆盖打包

## 使用方式

选中文字后展开右侧“文字描边”。默认关闭；开启后可修改颜色和粗细（0.2–8 pt）。关闭后保留设置，支持撤销与重做。描边在字形后绘制，避免遮住原文字颜色；换行和溢出检查为描边预留空间，较粗的描边可能需要扩大文本框。

描边使用文字自身的矢量轮廓，不需要字体厂商单独提供支持。普通可加载的 TTF/OTF 与随包黑体、宋体共用同一渲染路径；导入字体仍须满足原有格式、授权与嵌入条件。彩色表情、位图字形未作兼容承诺。实际验证覆盖内置中文黑体、宋体和导入 Arial 的界面与 PDF。

选中照片、贴纸或排版占位框后展开“边缘与边框”：

- 裁切形状：矩形、圆角、椭圆、拱形、票根切角、撕纸边缘、波浪边缘。
- 可调圆角大小或边缘幅度；边框支持无、细线、虚线、双线及拍立得留白，可调颜色和宽度。
- “清除边缘效果”恢复矩形、无边框；原图、原裁切区域保持不变。
- 可继续使用双击裁切、移动、缩放、旋转与透明度。这里改变图片外轮廓，不进行图片内容的液化或透视变形。

## 排版设计

编辑纪念册和编辑自建排版使用相同属性控件。模板的照片与贴纸占位可保存图片效果，填充素材和跨尺寸实例化时继承效果；文字保存描边开关、颜色与粗细。再次套用排版采用新模板的图片效果，原照片与裁切区域保留，确认前可预览。

11 套内置排版补充不同的图片处理：独白与留白采用小圆角；对话采用拍立得留白；来信使用轻撕纸边；章节使用拱形；票根采用切角双线。沿用各自的纸张、底色与文字配色，贴纸保留透明轮廓。所有内置文字描边默认关闭，避免装饰过多。

界面预览与 PDF 共用 SVG 裁切、边框及描边，效果参数保存在工程、历史与备份中。AI 批注协议增加 `outline` 与 `effects`，只允许修改对应类型的元素，并按原有规则校验后整批应用。

## 固定打包路径

以后升级版本只覆盖以下位置，不创建版本号文件夹：

| 内容 | 固定位置 |
| --- | --- |
| 程序目录 | `out/packages/Memorybook-win32-x64/` |
| 完整交付目录 | `out/delivery/` |
| 用户程序 | `out/delivery/Memorybook/Memorybook.exe` |
| 完整 ZIP | `out/Memorybook-Windows-x64.zip` |
| 仓库发布副本 | `releases/Memorybook-Windows-x64.zip` |

构建先使用固定的 `out/.package-stage/` 临时工作区，再覆盖程序目录；临时程序完成后移除。程序清单 `program-files.json` 用于清除上次版本遗留的程序文件，不递归删除整个目标目录。

覆盖程序保留 `data/`、`materials/imported-fonts/` 和未列入程序清单的个人文件。原始打包目录保留已有 `phrases.txt`。自 1.7.0 起，交付目录也保留已有短语；生成 ZIP 时独立使用随包默认库，避免把个人短语发出。目录与 ZIP 各自的 SHA256.json 分别对应其实际内容。交付 ZIP 仅收录程序清单、默认短语和说明校验文件，不收录目标目录里的个人工程、字体或设置。

打包前关闭要覆盖目录内的程序。文件被占用会报告错误，不强制结束进程；单个程序文件先写临时副本再替换，ZIP 生成完整后才替换上一份。多文件覆盖不等同于整体事务，过程中断时应关闭软件后重新打包完成。
